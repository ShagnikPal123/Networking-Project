# Agent: lead

Tier: **Strongest** (orange in the agent diagram)

## Use for

- Coordination
- Anything touching identity, session, membership, or failover
- Design changes
- Final review

## Never for

- Renames
- Formatting

## Checklists

- Basic: [checklists/basic.md](../checklists/basic.md)
- Advanced: [checklists/advanced.md](../checklists/advanced.md)

The lead gives the final review on any advanced-checklist task (step 6).

## Proposing splits

The lead proposes splits to the owner, and must propose the split first and wait for a yes. See `docs/design/04-agent-system.md`, "Splitting work".

## Memory

The design gives the lead no memory file of its own. It uses the shared `docs/agent/memory/decisions.md`.

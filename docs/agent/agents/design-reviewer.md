# Agent: design reviewer

Tier: **Strong** (blue in the agent diagram)

## Use for

- Reading a design or plan cold and listing what a builder would still have to guess

## Never for

- Rewriting the design itself

## Checklists

Runs the shared basic checklist ([checklists/basic.md](../checklists/basic.md)) plus its own:

**Basic**

- [ ] Could I plan this without asking anyone? List only gaps where a wrong guess matters.

**Advanced**

- [ ] Does it contradict an approved point, another design doc, or a logged decision?
- [ ] Does any module now need to call upward?
